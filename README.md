# 🌱 Market Growth Analysis for Meat Substitutes

## What it does
Analyzes the growth and market trends of meat substitute products using data analysis and visualization techniques to identify consumer demand and industry patterns.

## What I learned
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Market trend analysis
- Data visualization using charts and graphs
- Extracting business insights from datasets
- Working with real-world market data

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
